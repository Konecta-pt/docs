## O que é a Konecta

A Konecta vende **eSIMs de dados para viajantes** (mais de 210 países). A plataforma
divide-se em **8 repositórios**, alojados maioritariamente em **Cloudflare**
(Workers + Pages), com **fallbacks em Railway** para resiliência.

## Os repositórios

| Repositório | Tipo | Papel | Onde corre |
|---|---|---|---|
| [API-BACKEND](/repos/api-backend) | Worker (Hono) | API principal: auth, pedidos, checkout, admin, webhooks | `api.konecta.pt` |
| [API-ESIMS](/repos/api-esims) | Worker (Hono) | Integração com o fornecedor de eSIMs, ciclo de vida do eSIM | `eu-esims.konecta.pt` |
| [API-PAYMENTS](/repos/api-payments) | Worker (Hono) | Pagamentos (Stripe, MB WAY) | `payments.konecta.pt` |
| [admin-dashboard](/repos/admin-dashboard) | Pages (React) | Painel de administração | `admin.konecta.pt` |
| [konecta.pt](/repos/site) | Pages (React) | Website público / loja | `konecta.pt` |
| [payments-konecta-web](/repos/payments-web) | Pages (Next.js) | Checkout web | `pay.konecta.pt` |
| [App](/repos/app) | Expo / React Native | App móvel | iOS / Android |
| [LB](/repos/load-balancer) | Caddy (Railway) | Load balancer / failover CF↔Railway | `lb.statuskonecta.pt` |

## Stack transversal

- **Backends:** Cloudflare Workers + [Hono](https://hono.dev), TypeScript.
- **Frontends:** React + Vite (site, admin) e Next.js (checkout web), Cloudflare Pages.
- **Base de dados:** [Supabase (Postgres)](/database) — o service role é usado nos Workers/admin.
- **Pagamentos:** Stripe + MB WAY.
- **Fornecedor de eSIM:** esimcard.com (o CMLink está integrado mas [em pausa](/repos/api-esims)).
- **Monitorização/estado:** [OneUptime](/status-monitoring) (externo à Cloudflare).

## Princípios

- **Cloudflare = infraestrutura principal.** Tudo o que está em Workers/Pages é o
  caminho primário.
- **Railway = secundário (fallback).** Réplicas das APIs sob o domínio
  `statuskonecta.pt`, para o serviço se manter ON mesmo que a Cloudflare falhe.
- **IVA sempre 23%**, incluído no preço apresentado e cobrado.
