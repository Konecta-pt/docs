## O que é a Konecta

A Konecta vende **eSIMs de dados para viajantes** (mais de 210 destinos). A plataforma corre em **Cloudflare** (Workers \+ Pages), com **Supabase** como base de dados.

## Stack transversal

- **Backends:** Cloudflare Workers \+ [Hono](https://hono.dev), TypeScript.
- **Frontends:** React \+ Vite (site, admin) e Next.js (checkout web), Cloudflare Pages.
- **Base de dados:** Supabase (Postgres) — o service role é usado nos Workers/admin.
- **Pagamentos:** Stripe \+ MB WAY.
- **Fornecedor de eSIM:** esimcard.com.
- **Monitorização/estado:** [OneUptime](/status-monitoring) (externo à Cloudflare).

## Princípios

- **Cloudflare = infraestrutura.** Todos os serviços correm em Workers/Pages.
- **Estado via OneUptime** em `statuskonecta.pt` — se algo cair, é comunicado.
- **IVA sempre 23%**, incluído no preço apresentado e cobrado.
