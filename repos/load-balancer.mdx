## Papel

Reverse proxy **ativo-passivo**: Cloudflare (primário) → Railway (fallback), por
serviço, com health-check a `/health` e `lb_policy first`. É o **caminho de troca**
usado quando um serviço principal fica OFF.

## Upstreams (Caddyfile, valores reais)

| Serviço | Primário (CF) | Fallback (Railway) |
|---|---|---|
| API | `konecta-api.konecta-pt.workers.dev` | `api-backend.statuskonecta.pt` |
| eSIMs | `konecta-esims.konecta-pt.workers.dev` | `api-esims.statuskonecta.pt` |
| Payments | `konecta-payments.konecta-pt.workers.dev` | `api-payments.statuskonecta.pt` |

Health-check: `health_uri /health`, `health_status 2xx`, `fail_duration 30s`.
Config via env (`API_CF`, `API_RAILWAY`, …) com estes valores como defaults.

## Modelo pretendido (a fechar)
